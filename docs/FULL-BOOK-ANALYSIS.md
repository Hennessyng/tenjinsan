# Bounded experimental full-book analysis

This path tests available-text processing, structured analysis and independent evaluation machinery. Passing source, range, protocol or synthetic response tests is not evidence of model understanding or summary faithfulness. A first map is not whole-book coverage.

The published composition contains **no native release authority**. A compatible executable, matching caller tuple, saved consent, recovery record, environment value or request flag cannot enable native dispatch. Any private deployment authorization belongs to a separately reviewed trusted composition and is not included in this repository.

Historical binding validation is separate from active authorization. Stored native/recovery records retain their format, original consent, charged attempts and derived ceiling without becoming permission to execute. Recovery admission, claim/reservation and pre-write handling still check active authority; the published native gate denies it. Synthetic fixtures are explicitly non-live evidence.

The experimental plan partitions included ranges into a finite graph with per-node attempts and an immutable cumulative reservation. A scoped append-only recovery amendment can represent one additional owner-approved first-map slot without rewriting old unknowns or the original consent. It is not a general retry switch: unique atomic consumption and the stop barrier prevent reuse, another node or a fourth attempt. There is no public amendment-admission HTTP endpoint.

Recovery-aware logical audit export is not implemented and is blocked rather than dropping the amendment or charges. A received reply whose lease is lost remains durable; automatic resend or reclaim is not permitted by the stop barrier. Any further owner action requires separate reviewed handling.

Diagnostics retain finite public notification labels and safe failure sites, not source text, credentials, raw server messages or reasoning. Unknown names use only coarse size buckets. An acknowledgement pending in the collector is not proof of server wire order. A lost historical event name must not be reconstructed by guessing or replay.

The PDF implementation uses the locked WASM-only runtime and included notices. See [format and omission rules](MULTIFORMAT-IMPORT.md) and the ingestion notices for provenance limits. No hosted extraction, native optional-runtime fallback or provider probe is part of these tests.

Human assessment and separately authorized model evaluation are distinct gates. No publication-ready summary, completed live study, semantic score or general reliability claim follows from this implementation alone.
